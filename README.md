## 🏛️ Spesifikasi Bangunan 2 Lantai

* **Luas Lahan:** $500\text{ m}^2$ ($20.0\text{m} \times 25.0\text{m}$)
* **Luas Lantai 1 (Ground Floor):** $224.0\text{m}^2$ ($14.0\text{m} \times 16.0\text{m}$)
* **Luas Lantai 2 (Mezzanine Balkon):** $120.0\text{m}^2$ ($12.0\text{m} \times 10.0\text{m}$)
* **Total Luas Bangunan:** $344.0\text{m}^2$
* **Kapasitas Jamaah:** 360 Jamaah (160 Pria di Lantai 1 + 120 Wanita di Balkon + 80 Serambi)
* **Orientasi Kiblat:** Azimuth $294.5^\circ$ Barat-Barat Laut (BBL)
* **Akses Jalan:** Menghadap Selatan
